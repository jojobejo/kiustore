# Database - Akses WebView Lokal XAMPP

Tanggal: 2026-08-20

## Ringkasan

Tidak ada perubahan database untuk penyesuaian akses WebView lokal.

## Dampak Database

- Tidak ada tabel baru.
- Tidak ada kolom baru.
- Tidak ada index baru.
- Tidak ada migration SQL.
- Tidak ada perubahan data.

## Catatan

Perubahan hanya menyentuh konfigurasi URL dan redirect lokal agar project `C:\xampp\htdocs\kiustore` dapat dibuka dari Android emulator melalui `http://10.0.2.2/kiustore/`.
