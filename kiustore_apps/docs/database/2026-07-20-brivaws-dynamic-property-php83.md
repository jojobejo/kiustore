# Brivaws Dynamic Property PHP 8.3

## Dampak Database

Tidak ada perubahan database untuk perbaikan warning:

```text
Creation of dynamic property Brivaws::$CI is deprecated
```

Perbaikan berada di level kode PHP, yaitu deklarasi properti `$CI` pada `application/libraries/Brivaws.php`.

## Migrasi

Tidak diperlukan migrasi tabel, perubahan kolom, perubahan index, seed data, atau update data existing.
